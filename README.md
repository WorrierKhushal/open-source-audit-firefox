# Open Source Audit - Firefox

## 📌 Project Overview
This project performs a system-level audit of Mozilla Firefox using Bash scripts in a Linux environment.

## 🛠️ Scripts Included

1. **system_identity.sh**
   - Displays OS details, kernel, uptime, and OSS licensing message.

2. **package_inspector.sh**
   - Checks if Firefox is installed and shows version details.

3. **disk_auditor.sh**
   - Audits system directories and Firefox profile.

4. **log_analyzer.sh**
   - Analyzes log files and counts keyword occurrences.

5. **manifesto_generator.sh**
   - Interactive script to generate an open-source manifesto.
